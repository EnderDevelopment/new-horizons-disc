# Minecraft Bedrock Music Disc Add-on

New Horizons is a Minecraft Bedrock Edition add-on that adds a collectible music disc, a wandering trader offer, custom item naming, and resource and behavior packs. The New Horizons music disc costs 16 emerald blocks and is available through a weighted wandering trader trade with a 10% offer weight.

## Install

1. Ensure Minecraft Bedrock Edition 1.21.0 or newer is installed.
2. Package `behavior_packs/new_horizons_bp` as `new_horizons_bp.mcpack`.
3. Package `resource_packs/new_horizons_rp` as `new_horizons_rp.mcpack`.
4. Open both `.mcpack` files with Minecraft, or copy the folders into the corresponding development pack directories.
5. Create or edit a world.
6. Activate both `New Horizons Behavior Pack` and `New Horizons Resource Pack`.
7. Keep the resource pack dependency enabled when prompted.

For a single import, place both pack folders in one archive and rename the archive to `new_horizons.mcaddon`.

## Use

1. Enter a world with both packs enabled.
2. Find a wandering trader.
3. Check the trader's available offers.
4. When the weighted offer is selected, exchange 16 emerald blocks for one New Horizons music disc.
5. Place the disc in a jukebox to play it.
6. Use the creative inventory or the item identifier `new_horizons:new_horizons_disc` when testing or administering the item.

The disc has a maximum stack size of one, uses the vanilla cat record texture, and plays the built-in `record.cat` sound event. Its identifier is `new_horizons:new_horizons_disc`.
